# Naruto Bound — versão Godot 4 (em migração)

Abra o Godot 4 → **Importar** → selecione `godot/project.godot` → aperte **F5**.
A primeira importação demora, porque as texturas são comprimidas para a GPU.

- `scripts/` — batalha, interface, terreno e player das partículas Spine 3.8
- `assets/ninjas/` — dados e mídias exportados da versão web
- `tests/smoke.gd` — partidas completas IA x IA (`godot --headless --path godot --script res://tests/smoke.gd`)
- `tests/screens.gd` — capturas dos Ôgis (precisa de uma tela)

A versão web na raiz do repositório continua sendo a publicada no GitHub Pages.
